# Gradient Boosting From Scratch 

This repository contains a **from-scratch implementation of Gradient Boosting** using Python and NumPy, without relying on high-level machine learning libraries like `sklearn` for the core algorithm.

The goal of this project is to deeply understand how Gradient Boosting works internally by building it step by step.

---

##  Features
- Gradient Boosting implemented **from scratch**
- Uses **Decision Trees / Stumps** as weak learners
- Clear and modular code structure
- Easy to understand and extend
- Suitable for **learning, interviews, and ML portfolios**

---

##  What is Gradient Boosting?
Gradient Boosting is an **ensemble learning technique** that builds models sequentially.  
Each new model learns from the **errors (residuals)** made by the previous models and improves overall performance.

Key ideas:
- Sequential learning
- Weak learners (trees)
- Loss function optimization
- Learning rate control
